## 📦 插件列表

本仓库包含 4 个已上线插件，均可通过 UTools 页面「插件功能 → 增加插件」导入：

### 1. Web 重构 `Web重构_v26.14.3.js`

控制台 UI 全面重构，将原始页面升级为类操作系统的多分组导航体验。

- 🧭 **五大分组导航** — 状态 / 网络 / 系统 / 工具 / 扩展，顶栏胶囊切换
- 🎭 **信号心情图标** — 品牌标识实时反映信号状态（😊良好 → 😴离线），6 级渐变色
- 🏷️ **网络状态胶囊** — 运营商 + 网络类型徽章（5G 绿/4G 蓝）+ WiFi 状态 + 信号强度
- 👤 **登录状态指示** — CSS 纯绘图标 + 绿/红在线状态圆点
- 🌗 **双主题** — 日间 / 夜间 / 跟随系统，完整的 Light/Dark 主题
- 🖼️ **背景图系统** — Bing 每日风景 / 随机摄影 / CSS 渐变 / 自定义 URL
- ⚙️ **设置中心** — 桌面侧栏与手机下拉导航，统一内容滚动区；功能中心使用二级分类，消息转发、插件管理和兼容开关保持独立页面
- 📡 **网络诊断** — 汇总连接、信号、流量、网络地址和系统负载，支持脱敏报告与原生测速入口
- 🧠 **CPU 核心明细** — 默认直接显示全部核心的占用、频率与温度，无需点击展开
- 🎨 **10+ 美化选项** — 圆角、阴影、胶囊按钮、玻璃拟态、渐变标题、悬停动效等
- 📋 **配置管理** — 导出/导入配置、恢复默认
- 🔄 **版本与支持** — 关于页自动读取 GitHub 默认分支版本和 Stars；手动检查强制刷新，临时断网时可回退到 10099 本地服务最后一次成功结果
- 💾 **持久化保存** — 保存插件前检查登录状态，兼容空响应与多种返回格式，写入后自动回读比对，避免误报成功或失败
- 📱 **响应式适配** — 桌面 / 平板 / 手机三断点自适应

### 2. UTools 工具箱 `UTools-Beautifier-V1.0.1.js`

纯插件收纳管理，Bartender 模式让主界面保持整洁。

- 📦 **拖拽收纳** — 将插件按钮分为三个区域：主页可见 / 收纳箱 / 彻底隐藏
- 🔄 **智能抓取** — MutationObserver 监听 DOM，新安装的插件自动纳入管理
- ⚡ **轻量纯净** — 不含界面美化，专注收纳功能，无多余副作用

### 3. 电话与短信 `电话与短信_V1.3.3.js`

为路由器添加拨号和短信功能。

- 📞 **拨号盘** — 号码输入、拨号、挂断
- 💬 **短信会话** — 聊天式收发界面，支持长短信
- 📋 **通话记录** — 来电 / 去电 / 未接分类查看
- 🔍 **搜索过滤** — 通话记录和短信快速检索

### 4. 运营商信息 `运营商信息_V1.0.0.js`

识别当前 SIM 运营商，查看网络与 SIM 状态，并通过运营商官方服务号码查询余额和流量。

- **本地自动识别** — 结合运营商名称、IMSI/PLMN 和 ICCID 识别移动、联通、电信与广电
- **SIM 与网络概览** — 显示 SIM 状态、网络制式、信号、漫游、连接状态和脱敏设备标识
- **官方短信查询** — 支持移动 `10086`、联通 `10010`、电信 `10001` 的余额/流量查询
- **广电官方流量** — 可连接自托管的本地查询 API，显示官方小程序接口返回的总量、已用、剩余与更新时间
- **广电人工服务** — 已确认当前卡无法用菜单序号继续交互，改为直接拨打 `10099` 和打开中国广电官网
- **凭据隔离** — 插件只在浏览器本地保存代理 URL，不保存广电 App/小程序的 `Access`、`Session` 或加密请求数据
- **回执自动解析** — 从官方回复提取话费、流量、语音、短信、套餐名称与有效期
- **无效指令识别** — 官方回复“指令有误或不存在”时明确提示，不再显示成查询成功
- **回复自动追踪** — 查询后轮询短信列表，区分运营商回执与已发送指令
- **WebOS 直接集成** — 暴露 `window.KanoOperatorInfo.open()`，首页“运营商信息”卡片可直接打开

#### 中国广电自动查询

中国广电 `10099` 的短信菜单在当前实卡上会返回，但继续回复 `1` 或 `2` 会被官方判定为无效指令，因此插件已停用这个入口。仓库已集成 [10099-Tracker 本地服务](10099-Tracker/README.md)，可直接用 Python 运行，也保留 Docker Compose 部署方式：

1. 进入 `10099-Tracker`，运行 `./run-native.sh`；装有 Docker 时也可运行 `docker compose up -d --build`。
2. 打开 `http://127.0.0.1:8000/`，输入首次启动生成的管理令牌，粘贴中国广电小程序 `qryUserRes` 请求的完整 cURL。
3. 在插件“本地查询 API”中填写 `http://127.0.0.1:8000/traffic?details=1` 并保存；跨设备使用时将地址换成本机局域网 IP。
4. 插件读取 `total_gb`、`used_gb`、`balance_gb`、`updated_at` 和可选的 `details`，登录失效时会明确提示在代理端更新配置。

服务沿用了上游 MIT 许可的官方请求与流量解析逻辑，并额外隐藏配置回显、保护管理接口。不要把抓包得到的登录态直接写进插件或提交到仓库。

## 📖 安装方式

### 通过 UTools 页面导入（推荐）

> ⚠️ **已知问题：直接导入 `.js` 文件会报错（100% 触发），请使用以下方式安装。**

1. 打开 UTools 页面 `http://192.168.100.1:2333/`
2. 点击顶部 **「插件功能」** → **「增加插件」**
3. 先 **新建一个空文本插件**（不要直接导入 `.js` 文件）
4. 点击刚创建的空插件，进入 **编辑模式**
5. 将下载的 `.js` 文件内容 **全部复制粘贴** 进去，保存
6. 刷新页面生效

### 控制台注入（备用）

1. 打开 UTools 页面，按 `F12` 进入开发者工具
2. 切换到 **Console** 标签
3. 粘贴 `.js` 全部内容，按 **回车**
