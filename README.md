## 📦 插件列表

本仓库包含 3 个独立插件，均可通过 UTools 页面「插件功能 → 增加插件」导入：

### 1. Web 重构 `Web重构_v26.5.8.js`

控制台 UI 全面重构，将原始页面升级为类操作系统的多分组导航体验。

- 🧭 **五大分组导航** — 状态 / 网络 / 系统 / 工具 / 扩展，顶栏胶囊切换
- 🎭 **信号心情图标** — 品牌标识实时反映信号状态（😊良好 → 😴离线），6 级渐变色
- 🏷️ **网络状态胶囊** — 运营商 + 网络类型徽章（5G 绿/4G 蓝）+ WiFi 状态 + 信号强度
- 👤 **登录状态指示** — CSS 纯绘图标 + 绿/红在线状态圆点
- 🌗 **双主题** — 日间 / 夜间 / 跟随系统，完整的 Light/Dark 主题
- 🖼️ **背景图系统** — Bing 每日风景 / 随机摄影 / CSS 渐变 / 自定义 URL
- ⚙️ **设置面板** — 四页 Tab（导航分组 / 界面美化 / 首页背景 / 关于）
- 🎨 **10+ 美化选项** — 圆角、阴影、胶囊按钮、玻璃拟态、渐变标题、悬停动效等
- 📋 **配置管理** — 导出/导入配置、恢复默认
- 📱 **响应式适配** — 桌面 / 平板 / 手机三断点自适应

### 2. UTools 工具箱 `UTools-Beautifier-V1.0.1.js`

纯插件收纳管理，Bartender 模式让主界面保持整洁。

- 📦 **拖拽收纳** — 将插件按钮分为三个区域：主页可见 / 收纳箱 / 彻底隐藏
- 🔄 **智能抓取** — MutationObserver 监听 DOM，新安装的插件自动纳入管理
- ⚡ **轻量纯净** — 不含界面美化，专注收纳功能，无多余副作用

### 3. 电话与短信 `电话与短信_V1.3.3.js`

为路由器添加拨号和短信功能。

- 📞 **拨号盘** — 号码输入、拨号、挂断
- 💬 **短信会话** — 聊天式收发界面，支持长短信
- 📋 **通话记录** — 来电 / 去电 / 未接分类查看
- 🔍 **搜索过滤** — 通话记录和短信快速检索

## 📖 安装方式

### 通过 UTools 页面导入（推荐）

1. 下载对应 `.js` 文件
2. 打开 UTools 页面 `http://192.168.100.1:2333/`
3. 点击顶部 **「插件功能」** → **「增加插件」**
4. 选择下载的 `.js` 文件
5. 刷新页面生效

### 控制台注入（备用）

1. 打开 UTools 页面，按 `F12` 进入开发者工具
2. 切换到 **Console** 标签
3. 粘贴 `.js` 全部内容，按 **回车**
